# Organisation branding

The user identified TuluWorld Foundation as the organisation operating the Community Support Plan and authorised using its official website content and logo on 21 October 2026.

- Source: https://www.tuluworld.org.in/
- About source: https://www.tuluworld.org.in/about
- Original dark wordmark: https://www.tuluworld.org.in/static/tulu/assets/img/logo/LOGO-BLACK.png
- Original light wordmark: https://www.tuluworld.org.in/static/tulu/assets/img/logo/LOGO-WHITE.png
- Local assets: `public/brand/tuluworld-logo-dark.png`, `public/brand/tuluworld-logo-light.png`.

Original assets are preserved unaltered, not recreated or AI-generated. The main application uses the dark wordmark on a white backing for reliable contrast in public and private workspaces. Organisation copy is paraphrased and centralised in `src/content/organization.ts` with an official-source link on the About page. Legal registration numbers, payment QR codes, donation totals, and staff listings were not imported. No original-site payment functionality, policies, or fundraising rules replace the platform's locked financial rules.

Scope: main application public header, login/registration header, member/Admin/Coordinator shells, home page, page metadata and new `/about` page. The stakeholder demo is intentionally unchanged following the user's instruction to leave the demo and resume main-app work. No hosted demo deployment was performed for this branding change.
